# FinTrack – Smart Personal Finance & Expense Tracking App

## Project Overview
FinTrack is a UI/UX design concept for a smart personal finance and expense tracking mobile application. It is designed to help users monitor their income, track daily expenses, manage monthly budgets and understand their spending patterns.

## Project Objective
To design a clean, user-friendly and visually consistent mobile application interface that simplifies personal finance management.

## Tools Used
- Figma – UI design and interactive prototyping
- Inter Typography
- GitHub – Project documentation and file hosting

## Application Screens
1. Dashboard – Financial overview and recent transactions
2. Add Expense – Interface for recording expenses
3. Transactions – Income and expense history
4. Budget – Monthly budget and category-wise spending
5. Analytics – Visual representation of spending patterns
6. Profile – User profile and account settings

## Design Features
- Clean and minimal FinTech interface
- Consistent colour palette and typography
- Card-based dashboard layout
- Simple expense entry interface
- Budget monitoring and visual analytics
- Bottom navigation for easy access
